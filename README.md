# KALKUN KABUR!

A 3-lane endless runner in the style of Subway Surfers: a turkey escapes Farmer Bram across the farmyard, the barn and the kitchen. Three.js 3D with 9 .glb assets authored in Blender 4.5.17 — a layered-feather turkey, Farmer Bram with a turning head, ovens, fences, swinging carving knives, haystacks, corn, pumpkins and barrels.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080

Controls: ←/→ or A/D to switch lanes, ↑/Space to jump, ↓ to slide, P to pause, R to restart, M to mute. Touch controls included.
